# Referência visual

A imagem incluída nesta pasta foi fornecida pelo utilizador como referência para uma biblioteca de componentes de gestão hospitalar.

## Como usar
- Inspirar-se na variedade de botões, navegação lateral, toggles, controlos segmentados e hierarquia de cartões.
- Aplicar a identidade do **NV.Digital**, com cores moderadas e contraste nítido.
- Não copiar nome, logótipo ou marca visível na referência.
- Adaptar a interface à stack e aos componentes reais do projeto.
- A imagem não é código funcional nem prova de que qualquer componente esteja implementado.
